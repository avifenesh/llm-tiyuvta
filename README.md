# llm-tiyuvta

> **Retired.** The tiyuvta inference endpoint (api.tiyuvta.ai) closed on 2026-09-28 and will not come back.
> This plugin no longer works and gets no further updates.

This was an [LLM](https://llm.datasette.io/) plugin for the tiyuvta inference endpoint.

Tiyuvta now builds AI integration for non-tech companies: tailored systems, personal guidance and private deployment options. See [tiyuvta.ai](https://tiyuvta.ai/).

## Remove the plugin

```bash
llm uninstall llm-tiyuvta
```
